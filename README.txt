Предложение 1: указать в правой панели существа информацию о семейном роде в следующем стиле:
1) Папа: X, Мама: Y (если создан игроком, то по приколу укажешь на "Небеса")
2) Супруг(а): Z
3) Дети: Сыновья - A,B... Дочери - C,D... (если их нет, просто "Нет")
Предложение 2: создать некое Древо Родословной.
-Открыть древо можно двумя способами: кнопкой "Геном" в правой панели существа (над кнопкой "Психика") или на кладбище с идентичной кнопкой рядом с "Подробности" (если последней уже нет - смещаем на её место). Каждый круг показывается в следующем стиле: [Невидимый прямоугольник для креста (см. ниже)] [Сам круг с цветом для определения пола] [Имя круга]
-При нажатии показывается окошко, которое демонстрируется в виде Древа. Ровно по центру стоит наш выбранный кружок, сбоку (если есть) стоит партнёр, с которым установлена связь (см. ниже). Выше сущности - его/её предки (если есть), ниже - потомки (если есть). Если данных на окошке больше, чем оно физически вмещается, то видимую область можно будет вручную двигать с помощью зажатия ЛКМ с последующим перемещением.
-Связи между кругами показываем с помощью линий, которые могут рисоваться ровно или под определёнными углами в зависимости от контекста. Конкретный круг может показывать до 6 степеней предков и потомков.
-Если на момент открытия окошки какое-то из показываемых существ уже мертво, то слева от рядом в том самом прямоугольнике прорисуем небольшой крест из линий.
